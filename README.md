# ⚡ Pokémon Gacha & Tactical RPG ⚡

Un jeu de rôle stratégique Pokémon gratuit (Free-to-Play) intégrant :
- 🥚 Un système d'invocation par œufs et bannières tournantes.
- ⚔️ Un mode PvE complet (Aventure, Raids Dynamax, Dimensions).
- 🛡️ Un mode PvP compétitif en ligne.
- 👥 Une gestion d'équipe avancée (IV, EV, Talents, Objets tenus).
- 🌐 Sauvegarde cloud et comptes joueurs.
